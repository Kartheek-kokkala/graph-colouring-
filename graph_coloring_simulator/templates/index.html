What is Graph Coloring?

Graph coloring is the process of assigning colors (or numerical labels) to the vertices of a graph such that no two connected (adjacent) vertices have the same color.

1. Vertex (Node)

Represents an entity, such as a university course, an airport gate, or a wireless cell tower.

2. Edge (Link)

Represents a connection, shared resource, or conflict between two vertices.

3. Proper Coloring

A coloring is proper if for every edge (u, v), Color(u) ≠ Color(v).

4. Chromatic Number (χ)

The minimum number of colors required to properly color the entire graph.

About Greedy Coloring Algorithm

The greedy algorithm colors vertices one by one in sequence. For each vertex, it considers the colors already assigned to its neighbors and picks the first available smallest color number.

Python Function: greedy_coloring(graph) Python 3 
def greedy_coloring(graph):
    color = {}

    for vertex in graph:
        used_colors = set()

        for neighbor in graph[vertex]:
            if neighbor in color:
                used_colors.add(color[neighbor])

        current_color = 0

        while current_color in used_colors:
            current_color += 1

        color[vertex] = current_color

    return color

Real-World Applications of Graph Coloring

Graph coloring translates complex real-world scheduling and resource allocation problems into straightforward mathematical models:

1. Exam Timetable Scheduling

Vertices represent college courses. Edges connect courses taken by the same students. Colors represent exam time slots so no student has overlapping exams.

2. Map Coloring

Adjacent countries or states sharing a geographical boundary must receive different colors so they can be clearly distinguished on printed maps.

3. Frequency Assignment

Radio transmission towers with overlapping coverage areas are assigned different frequency channels to avoid electromagnetic signal interference.

4. Register Allocation in Compilers

Variables that are active simultaneously cannot occupy the same physical CPU register. Compilers use graph coloring to allocate hardware registers efficiently.

5. Task & Resource Scheduling

Tasks competing for identical machines, meeting rooms, or flight boarding gates are scheduled in conflict-free time slots.
